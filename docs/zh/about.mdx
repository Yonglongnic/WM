# 关于本地部署

本项目是一个本地实时全球态势仪表盘，将公开新闻、地缘政治、军事、金融、能源、气候、航空、海事和网络安全信号集中到一个浏览器界面。

本地版面向单机 Docker 部署。前端、API sidecar、relay、Redis 缓存和配置都在项目容器栈内运行，宿主机不需要全局运行时，也不依赖独立登录服务。

## 平台能力

- 规范化公开数据源的信号；
- 跟踪数据新鲜度，上游不可用时保留最近有效缓存；
- 通过地图图层和领域面板展示带来源上下文的数据；
- 对空的可选 Key 使用免费公开数据源或优雅降级；
- 为仪表盘和嵌入页面提供本地 API。

## 本地访问模式

Compose 开启本地公开访问。普通页面和面板不要求注册、登录或会员资格。可选的 AI 和数据源 Key 可以增加覆盖范围，但缺少它们时应显示空状态或使用免费替代源。

## 数据和许可证

各上游服务自行负责数据许可证、调用限制和归因要求。本地项目会保留必要的数据源名称和归因信息；源代码许可证以项目根目录的 `LICENSE` 文件为准。
